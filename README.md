# 牛马鼓励器（Niuma Motivator）

一个干净的 Windows 桌面悬浮窗：实时显示你今天已经赚了多少钱，一秒一秒地往上涨。

## 功能

- **实时跳字**：按你的月薪 / 上下班时间 / 午休 / 工作日，每秒刷新「今日已赚」
- **今日进度条**：按日薪进度推进，下班自动封顶
- **状态胶囊**：距下班倒计时、午休中、休息日、距发薪日倒计时
- **小目标心愿单**：显示「还差 ¥xx · 约 n 天」，进度条随收入实时推进，赚够自动变绿 🎉；图标从 34 个备选里点选
- **牛马语录**：每 5 秒自动换一句，点一下换下一句
- **透明度调节**：设置里拖滑杆，或在悬浮窗上按住 Ctrl 滚轮快速调节
- **换肤**：6 套预设皮肤 + 自定义配色，还能**上传图片当背景**（自动压缩）；每个皮肤各自记住自己的不透明度，切换皮肤时自动带出；**设置窗口整页跟随皮肤配色**
- **鼠标穿透**：Ctrl+Alt+N / 悬浮窗上的 👻 按钮 / 托盘菜单，穿透后不挡任何点击；开启时图标亮起并画斜杠，取消即摘掉
- **一键重置**：设置「其他」卡片里连点两次，清空所有数据恢复初始状态（暗夜金皮肤 · 月薪 ¥5,000）
- **托盘常驻**：显示隐藏、置顶、鼠标穿透、退出
- **自动保存**：配置存放在 `%APPDATA%\niuma-motivator\config.json`，全程不联网

## 运行

需要 Node.js 18+（已在本机验证 v22）。

```bash
npm install
npm start
```

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+N` | 切换鼠标穿透 |
| `Ctrl+Alt+H` | 显示 / 隐藏悬浮窗 |
| `Ctrl` + 滚轮（悬浮窗上） | 快速调节透明度 |

## 使用小贴士

- 悬浮窗**任意位置按住即可拖动**，位置会自动记住
- 鼠标悬停时右上角出现 ⚙（设置）、👻（穿透）、✕（退出）三个按钮
- 设置窗口里改任何东西都会**即时生效、自动保存**

## 打包成 exe（可选）

```bash
npm i -D electron-builder   # 首次才需要
npm run dist
```

打包产物在 `dist/` 目录：

| 产物 | 说明 |
| --- | --- |
| `牛马鼓励器 1.0.0.exe` | 免安装 portable 单文件（约 106 MB），拷到任何 Windows 机器双击即用 |
| `win-unpacked/牛马鼓励器.exe` | 解包版（目录约 240 MB），固定在本机使用时跑它，启动更快 |

- 打包后「开机自动启动」开关才会生效（开发模式下不生效）
- 未做代码签名：首次运行如被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」
- portable 单文件每次启动会先解压到临时目录，首启略慢（几秒），介意就用 `win-unpacked` 版

## 开发

```bash
npm test        # 单元测试（计算 / 皮肤 / 配置核心）
npm run dev     # 打开开发者工具
npm run capture # 自动截图悬浮窗和设置窗口到 shots/（自检用）
```

## 说明

- 首次使用默认：月薪 ¥5,000 · 暗夜金皮肤，全部数据可随时重置回这个初始状态
- 周末 / 非工作日不计入收入；每天 0 点自动归零重新开始
- 「每月工作日」按勾选的工作日自动换算（5 天制 ≈ 21.7 天/月）
- 午休时间默认不计薪，可在设置里关闭
